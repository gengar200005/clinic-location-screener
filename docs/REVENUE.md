## 해석 제한

일반의원은 내과 전용 분류가 아니다. 카드 기반 추정값은 공단부담금 포함 실제 총매출이 아니다. 거래 건수는 환자 수가 아니다. 행정동 값을 반경 진료권에 인구비례 배분하지 않는다.

원자료 `당월_매출_금액`의 의료업종 적용 기준은 추가 확인이 필요하다. 서울시의 2026-02-09 보도자료는 상권분석 자료를 분기 월평균으로 설명하지만 의료업종 원자료에 대한 직접 설명은 아니다. 2026-10-28 화면부터 원자료 금액과 주민 1인당 환산액을 표시하되 월매출·분기총매출로 환산하지 않는다. JSON의 amount/per_shop는 원자료 금액 및 단순 점포 수 나눗셈이며 실제 의원 평균 매출을 뜻하지 않는다.

50세 이상 비중은 매출액 기준(50대+60세 이상)이며 환자 비중 또는 50~69세 비중이 아니다. 점포 수는 매출 표본 수가 아니다. 동일 의원 패널을 추적한 결과도 아니다.

시계열은 분기 간 동일 코드로만 연결한다. 행정구역 개편·경계·표본·모형 변경은 외부 검증이 남아 있으므로 성장률을 급여 진료 수요의 인과적 증가로 해석하지 않는다. 2026Q3는 확보된 원자료에 없으며 생성하지 않았다.

## 지도에서 매출 확인

`index.html`의 행정동 경계 색상은 선택 분기의 전년 동기 대비 증감이다. 현재 후보 목록의 필터를 따른다. ‘전체 행정동 탐색’으로 범위를 넓힌 뒤 지역·동명으로 검색할 수 있다. 경계 클릭 또는 키보드 Enter/Space와 후보 선택이 지도 아래 매출 요약 및 기존 주변 의원 탐색에 함께 연결된다. 분기별 추세는 요약에서 펼친다.

서울 매출은 기존 `matches`의 후보 ID·전체 이름·unique_exact_name 방식이 모두 일치할 때만 사용한다. 경계는 기존 후보 ID와 전체 이름까지 일치할 때만 표시한다. 공식 코드 교차표나 시점별 경계 일치를 새로 검증한 것은 아니며 화면에 참고값임을 표시한다. 경기 미확보·서울 미연결·매출 미수록은 0%와 다른 회색이다. 반경 변경·기준점 이동으로 행정동 매출을 재계산하지 않는다.

검증: `node --test tests/test_revenue_map.cjs` 2개, 기존 Python 테스트 10개. 브라우저에서 마포구 16개 경계/15개 증감, 지도 상암동 선택, 2026Q1/Q2 변경, 경기 일산1동 미확보, 기존 반경 1.5km 기관 목록 확인.
