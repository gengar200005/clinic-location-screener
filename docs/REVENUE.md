## 해석 제한

일반의원은 내과 전용 분류가 아니다. 카드 기반 추정값은 공단부담금 포함 실제 총매출이 아니다. 거래 건수는 환자 수가 아니다. 행정동 값을 반경 진료권에 인구비례 배분하지 않는다.

원자료 `당월_매출_금액`의 의료업종 적용 기준은 추가 확인이 필요하다. 서울시의 2026-02-09 보도자료는 상권분석 자료를 분기 월평균으로 설명하지만 의료업종 원자료에 대한 직접 설명은 아니다. 이번 화면은 상대 증감률과 지수만 표시하고 월매출·분기총매출로 환산하지 않는다. JSON의 amount/per_shop는 원자료 금액 및 단순 점포 수 나눗셈이며 실제 의원 평균 매출을 뜻하지 않는다.

50세 이상 비중은 매출액 기준(50대+60세 이상)이며 환자 비중 또는 50~69세 비중이 아니다. 점포 수는 매출 표본 수가 아니다. 동일 의원 패널을 추적한 결과도 아니다.

시계열은 분기 간 동일 코드로만 연결한다. 행정구역 개편·경계·표본·모형 변경은 외부 검증이 남아 있으므로 성장률을 급여 진료 수요의 인과적 증가로 해석하지 않는다. 2026Q3는 확보된 원자료에 없으며 생성하지 않았다.

### 2026-10-27 재검증 — 실제 매출 연동 미완료

- 공식 카탈로그: https://www.data.go.kr/data/15151650/fileData.do
- 제공기관 경기도, 데이터셋 `카드매출_행정동_집계` (`H92OOSWZXICJM0UO4IHH38259217`).
- 카탈로그는 기준년월·행정동코드·중분류업종코드·매출금액, CSV 36,243행, 수시/1회성 자료로 설명한다. **원자료의 실측 행 수와 실제 관측 기간은 미확인**이다. 제목의 20250918을 시계열 종료 월로 사용하지 않는다.
- 공식 이용조건은 무료, **공공저작물 출처표시 제1유형**. 출처를 경기도로 명시한다. 재색인 서비스의 cc-zero 표기를 채택하지 않는다. 원본 부속 조건은 확보 후 대조한다.
- 상세 페이지 GET은 HTTP 200이나 645,527바이트에서 HTML이 끊긴다. 카탈로그에 연결된 공개 CSV 다운로드는 정상 세션·Referer와 공개 폼의 CSRF 토큰으로 GET/POST 모두 HTTP 500. 세션 없는 GET은 HTTP 200 오류 스크립트였다. 로그인이나 API 키가 필요하다고 단정하지 않는다.
- 의원 업종 코드와 포함 범위는 아직 검증 불가. 중분류 의료업이나 서울 CS200006을 경기 의원 업종으로 간주하지 않는다. 지역화폐·전업종 매출로 대체하지 않는다.
- 208개 기존 후보 ID를 보존하고 매출 코드는 null로 유지한다. 검증 연결 0개, 추세 0개. SGIS/MOIS 체계, 유효기간, 부천 등 행정구역 개편 및 동명 중복 확인 전 단순 동명·접두사 연결을 금지한다.

`data/manual/revenue/gyeonggi/verification.json`은 사람이 확인한 근거와 미검증 항목,
`acquisition.json`은 재수집 결과(응답 상태·크기·SHA256, 토큰 제외)를 기록한다.
`web/data/gyeonggi-revenue-scope.json`과 화면은 이를 읽어 여섯 단계 검증 상태를 표시한다.
원자료 확보와 의미 검증은 별개이며, 다운로드가 성공해도 자동으로 화면이나 순위에 반영하지 않는다.

```bash
python -m scripts.fetch_gyeonggi_revenue
python -m scripts.build_gyeonggi_revenue_scope
python -m unittest tests.test_revenue tests.test_gyeonggi_revenue
node --check web/revenue.js
```

수집기는 HTML/오류/빈 응답/잘못된 CSV를 원자료로 저장하지 않는다. CSV 모양을 통과한 파일도
SHA256 이름으로 보관할 뿐 `downloaded_unverified` 상태다. 업종 검증을 대신하지 않는다.
재실행 후 acquisition.json의 상태와 실제 파일을 반드시 확인한다.

### 연동 재개 조건

1. 공식 원본 CSV와 해당 업종·행정동 코드표, 집계 설명 확보.
2. 의원 단독 분류 여부와 치과·한의원·약국 포함 범위, 금액 단위·추정/실측·표본 기준 검증.
3. 실제 기준년월·중복 키·누락·0·비공개 값 검사. 전월은 정확한 직전 월, 전년은 정확한 전년 동월끼리만 비교. 누락 보간 금지.
4. 후보별 공식 코드 대응과 관측 시점 경계 일치 검증. 분동·합동을 단순 합산하거나 인구비례 배분하지 않음.
5. 검증된 동·기간만 추세 연결하고 미연결 사유를 별도로 표시. 서울 분기 추정매출과 경기 월 카드매출의 수준·성장률을 동일 기준처럼 혼합하지 않음.

현재 원자료 서버 오류로 1단계에서 막혀 있다. 이 변경은 검증 상태와 수집 재현성을 보완한 것으로, **경기 매출 추세 연결 완료를 의미하지 않는다**. 기존 입지 점수·순위·서울 매출 스냅샷은 변경하지 않는다.
