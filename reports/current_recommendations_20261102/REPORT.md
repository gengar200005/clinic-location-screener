## 3. 새 선정 규칙과 가정

규칙은 첫 결과 확인 전 `config/current_recommendations.json`에 기록했다. 원하는 지역이 나오도록 가중치·기준을 사후 조정하지 않았다. 이후 수정은 연결 오류 방지, 출처 표시, 누락 상태 구분과 반응 검증에 관한 것이다.

### 공통 수요·공급

1. 서울/경기를 분리하고 같은 비교군 안에서 상대 위치를 계산한다. 현재 개인·지역조건을 적용한다. 통근 확인 단계는 과거 경로 추정상60분 안쪽 →60분 경계 → 근접 근거 부족 순으로 조사한다. 경계·미확인은 실측 불가 판정이 아니다.
2. 주거 수요는 기존50~69세 배후인구 하한 추정의 백분위다. 총 배후인구·상한도 참고로 표시하되, 서로 강하게 관련된 수요 항목을 별개의 호재로 중복 가산하지 않는다.
3. 관측 공급부담은 다음 상대 비율의 백분위 중앙값이다: 연령수요/(1+내과전문의 의원), 연령수요/(1+내시경 의원+2×내시경 병원), 연령수요/(1+위암검진 지정 의원).
4. 기본은 수요50% + 공급부담50%. 두 직선반경1km/1.5km 중 더 약한 결과를 기준으로 삼는다. 기관 수가 많다는 이유만의 탈락, 적다는 이유만의 진입기회 판정은 없다.

분모의1은 신규기관을 가정하는 비교 정규화이고, 병원2도 조사 배분 가정이다. **실제 검사 처리능력·FTE·환자 수를 뜻하지 않는다.** 공급 간 중복, 동일 인구가 비율에 반복 사용되는 문제와 오래된 신고자료의 한계가 있다. 전문의/내시경/검진 수는 서로 다른 관측이며, 내시경 장비 의원에 내과 외 진료과가 포함될 수 있다. 실제 내시경·검진 운영과 가동률은 별도 확인한다.

### 서울 의료소비의 제한적 반영

- 2025Q3~2026Q2 표시값4개를 2024Q3~2025Q2의 정확한 대응분기와 비교한다. 합 비교는 같은 정의의4개 표시값 비교지표이며 연매출로 환산하지 않았다. 원자료 금액·거래 건수의 행정동/업종/기간이 일치할 때만 나눈다.
- 4분기 중3개 이상 금액·거래 동반 증가, 4개 표시값의 거래 합 증가, 최신분기 거래 비감소면 지속 증가로 +5.
- 3개 이상 거래 감소하고 거래 합도 감소하면 −5. 금액 합만 늘고 거래는 증가하지 않는 다른 경우 −2. 혼재는0 조정.
- 매출·거래·건당 금액을 세 개 독립 호재로 가산하지 않는다. 건당 금액은 산술 설명이다. 일반의원 전체 카드 추정 활동이지 내과 환자 수, 공단 포함 총매출, 신규기관 몫이 아니다.
- 미연결/대응분기 부족은 관측치를0으로 채우지 않는다. 조사 가정 구간[-5,+5]를 부여하고 하한으로 운영 순서를 정한다. 이 구간은 통계적 신뢰구간이 아니다. 관측 항목이 적어서 유리해지지 않도록 하며, 상한 적용 결과도 민감도에 표시한다.
- 경기에는 이 축 자체를 넣지 않는다. 별도의 공통 수요·공급 비교를 유지한다. 서울과 같은 통합 점수/종합 순위로 섞지 않는다.

### 묶음·순서·실행 가능성

5단위 조사군 → 공통 구조지수 → 안정적인 후보ID 순으로 조사 순서를 정한다. 같은 군 내 순서는 작은 수치 차이를 성공 우열로 보장하지 않는다. ‘공동1위’만 나열하지 않고 실제 연락할 순서를 제공한다.

인접 좌표의 중복 배후·경쟁을 줄이기 위해 같은 행정동에서 대표 조사점1개를 선택한다. **이것은 조사 묶음이지 실제 생활권 합병이 아니다.** 거리만으로 철길·하천·대로 양측을 같은 시장으로 합치지 않았다. 모든 원좌표를 CSV에 남기고 비대표 과거점에는 현재 대표ID를 연결했다. 민감도는 대표 교체를 허용한 같은 행정동의 순서 범위다.

실제 건물 확보는 시장 순위에 가산하지 않는다. 방문 준비는 별도 함수로 판정한다. 층·현 공실·전용95~100평·전체 임상배치/확장·승강기·당일 확인·근거가 모두 있어야 방문 준비 완료가 된다. 한 건물이70평이거나 공실이 아니라고 생활권 전체를 탈락시키지 않는다. 기존 광고를 새 공실로 바꾸지 않는다.

입력 양식은 `data/manual/current_building_verifications.json`. `layout_verified`는 내시경·초음파·검사실·회복실·향후2~3인 확장을 모두 확인했다는 뜻이다. 방문 준비는 의료기관 개설 허가나 계약 적합 판정이 아니다. 현재 검증 완료 입력은0건이다.

주소는 분석점의 출처이며 입주 가능 매물이 아니다. 세 권역의 전용95~100평 가용층을 먼저 문의하고, 근거가 생긴 건물만 방문한다. 아직 없다면 같은 권역의 다른 건물을 계속 탐색할 수 있다.

경기 별도 조사 상위는 소사본1동·소사본동·안산 부곡동 등이다. 경기 의료소비 검증이 없으므로 서울 순서와 직접 비교하지 않는다. 부천이 다시 여러 곳 들어온 것을 임의로 감점/지역할당으로 조정하지 않았다. 같은 배후·교통 장벽·행정개편 및 실제 공간 확보를 확인해야 한다.

## 5. 새 의료소비 반영의 영향과 민감도

새 공통 규칙을 고정한 채 의료소비 조정만 빼 본 대조에서는 서울30곳 중25곳이 같고5곳이 달랐다. 의료소비 반영 후 시흥1동·월계3동·중계본동·장안1동·왕십리도선동이 들어오고, 우장산동·미성동·하계1동·남가좌1동·신월7동이 우선군 밖으로 갔다. **과거 전체 목록 변화40개를 모두 매출 효과라고 설명하지 않는다.** 모집단과 공통 조사 규칙 변경 효과도 있다. 경기는 의료소비를 적용하지 않아 이 대조에서15곳 모두 같다.

수요 비중35/50/65%, 병원 공급부담1/2/3, 반경1km/1.5km의18개 대안과 서울 미연결 추세 상한1개를 검사했다.

- 서울19대안: 현재30곳과의 겹침17~30. 모든 대안에 공통으로 남는 행정동 조사 묶음은8개. 현재30곳 전체가 강건하다고 부르지 않는다.
- 경기18대안: 현재15곳과의 겹침13~15. 모든 대안 공통12개. 실제 사업성·시장유입 검증이 아니라 같은 캐시/다른 조사 가정에서의 안정성이다.
- 첫3권역은 모두 대안 상위7 이내다. 순서 범위를 표시하고 실제 공간 근거가 확보될 때 방문 결정을 내린다.
- 같은 배후/기관을 공유하는 좌표를 독립 표본으로 세어 통계적 유의성이나 성공확률을 계산하지 않았다.

## 6. 앱과 설명을 통합한 방식

단일 현재 원본: `web/data/current-recommendations.json`. 생성: `scripts/build_current_recommendations.py`. 고정 시범6곳 파일은 과거 스냅샷으로 보존했다. 기존 `scripts.market_demand` 실행은 이제 현재 생성기로 연결되며, 공통 의료·기간·결측 계산 함수는 재사용한다. 지역명별 `judgement_notes` 고정 판단은 제거했다.

- 메인 기본 목록/정렬/선택/상세·임장 탭 → 현재 원본. 기본 서울30, 경기 별도15. 현재 전체 대표 조사점도 조회 가능.
- `current-fieldwork.html` → 같은 원본·같은45곳·같은 상태. 시장 우선군 밖에서 검증된 건물이 생겨도 방문 준비를 별도 표시하도록 구현·검사했다.
- `market-demand.html` →850개 허용 후보/과거 비교점 선택, 우선군45개 비교, 같은 후보ID·좌표·판단·버전 사용.22분기 의료금액/거래/건당 금액/점포와 실제 연령자료, 상권 참고 자료 유지.
- 과거 v3 임장 화면과 기존 수동 실전/매출 근거 화면 → 과거 기록 표시와 현재 화면 링크. 과거 정릉 표를 지워 역사적 결과를 변조하지 않았다.
- 기존 전체 행정동 매출 경계·후보 선택·의원 반경 탐색 유지. 기본 경계745개는 채색0, 커서를 올린 동만 색이 들어오는 방식 유지.
- 지역별 자동 설명은 현재 계산 수치·분기 방향으로 생성한다. 과거 수동 의견은 작성일/출처/관련 입력 해시/재검토 표시로 분리했다. 월계·청량리 인근·수색의 방문기록은 정확한 중첩 미확인이라고 표시하며 공간 부족을 동 전체 부적합으로 확대하지 않았다.

## 7. 검증 결과와 한계

- 실행 가능한 Python100개, Node12개 통과. API를 부르지 않는 고정 테스트 자료 사용. 증가→감소 시 설명/조사군 변화, 단일 분기 급등 차단, 금액 증가·거래 감소, 정확한4분기/분모0/결측/비공개, 고유키, 많은 공급 후보 유지, 기존6곳 밖 진입, 공간 근거에 따른 방문 상태, 특정 건물 부적합의 지역 탈락 방지, 개인조건 제외, 안정적인 순서, 현재 화면 원본/버전 일치 검사.
- 기존3모듈은 수집 단계에서 미설치 의존성으로 실행 불가: `test_hira_guard.py`의tenacity, `test_pop_weighted_centroid.py`/`test_web_export_v7.py`의geopandas. 원인과 로그는 `full-collection.txt`. 전체 통과라고 표현하지 않는다. 기존 경고2개도 `pytest.txt`에 남겼다.
- 브라우저: 메인/임장 탭/시장/별도 임장 페이지에서 같은 버전 확인,45개 상태 일치, 정릉 현재 목록 제외, 새 후보 선택, 구로 설명의 실제 거래 감소, 경기 별도15곳, 의원1km→1.5km 탐색, 매출 분기 변경, 전체745개 경계 무채색 기본상태 확인. 데스크톱1280·모바일390에서 루트 가로 넘침 없고 표는 내부 스크롤. 증거 `desktop.jpg`, `mobile.jpg`, `browser_validation.json`.
- 보호160파일 해시 불변, 원본을 다시 수집하거나 공간분석 전체를 재실행하지 않았다. 신규 계산은 캐시 연결·상대 비교·정렬이다.
- 이 테스트는 개원 성공·신규 환자 유입 예측력 검증이 아니다. 실제 보행 장벽·기관 가동률·예약·전용도면·현 공실·고정비는 여전히 필요하다.

## 9. 재실행·로컬 확인·최소 현장 정보

활성 작업 폴더에서:

```powershell
$env:PYTHONIOENCODING='utf-8'
& ../clinic-location-screener/.venv/Scripts/python.exe -B -m scripts.build_current_recommendations
& ../clinic-location-screener/.venv/Scripts/python.exe -B -m scripts.audit_current_recommendations
& ../clinic-location-screener/.venv/Scripts/python.exe -B -m pytest -q -p no:cacheprovider --ignore=tests/test_hira_guard.py --ignore=tests/test_pop_weighted_centroid.py --ignore=tests/test_web_export_v7.py
node --test tests/*.cjs
& ../clinic-location-screener/.venv/Scripts/python.exe -B -m http.server 8771 --bind 127.0.0.1 --directory web
```

기존 원본 폴더의 `reports/screening_v3/2026-10-23` 캐시를 읽는다. 외부 API 호출은 없다. 현재 파생 결과만 갱신하고 과거 점수·원본은 덮어쓰지 않는다. 원본 폴더가 없는 환경에서는 재생성에 이 캐시가 필요하며, 이미 생성된 웹 JSON/CSV는 독립 조회 가능하다.

- 메인: `http://127.0.0.1:8771/index.html?v=515caf22c80f`
- 현재 조사/방문 준비: `http://127.0.0.1:8771/current-fieldwork.html?v=515caf22c80f`
- 시장 상세: `http://127.0.0.1:8771/market-demand.html?v=515caf22c80f`
- 전체 CSV: `web/data/current-inventory.csv` / `all_candidate_decisions.csv`
- 과거 비교: `old_v3_comparison.csv`, `legacy_main_membership.csv`, `v7_reference_membership.csv`, `v7_all_reference_coverage.csv`
- 규칙/민감도/출처: `config/current_recommendations.json`, `sensitivity.json`, `input_hashes.json`, `VALIDATION.json`

사용자가 지금 확인할 최소 정보는 첫3권역에서 **정확한 주소·가능 층·현 공실·전용면적 도면·확인일/출처**다. 길음은 원본 주소/좌표 연결도 확인한다. 도면상 내시경·초음파·검사·회복·확장 배치, 승강기/환자 동선, 주차, 설비 제한이 확인되면 방문 준비 상태를 갱신한다. 중개광고 유무나 한 건물의 공간 부족만으로 시장 우열을 바꾸지 않는다.
