불러오는 중

아래는 2024년 공식 코드표의 전체 동명이 일치한 과거 의료기관(J0) 관측자료입니다. 의원 단독 매출·현재 건물 매출로 해석할 수 없습니다. 시점별 행정경계·금액 단위·추정 방식·신규 업종코드 대응이 미검증이므로 서울 금액과 비교하거나 추천 점수에 더하지 않습니다.

전체 파일에는 2018년1월~2025년6월이 있지만, 확인한 J0는 2023년12월까지이며 중간에 누락된 달이 있습니다. 그래프나 전년 비교로 빈 기간을 메우지 않았습니다.

키 파일 등록 확인 완료. 실제 확보는 공식 공개 CSV 세션 다운로드 방식이며 API 키 인증 성공을 뜻하지 않습니다. 확인일2026-11-02.

제공하신 매뉴얼로 보완한 해석

기본 매뉴얼 PDF12~13쪽은 여러 카드사 자료 통합, 점유비·현금 사용비중 등을 활용한 추정, 전수화 보정을 설명합니다. 단일 카드사의 관측액이나 개별 내과의 실제 총매출로 해석하면 안 됩니다.

다만 매뉴얼의2024년 대상·테이블과 ZIP의2018~2025년 자료가 완전히 대응하는지는 미검증입니다. ZIP 금액의 원 단위·추정 방식을 전체 기간에 확정 적용하지 않았습니다.

원본 비교: ZIP과 이전 공개 다운로드는 모두1,750,297행입니다. J0관측28,368건의 키가 일치하지만27,528건에서 숫자 표현값이 다릅니다. 금액을 합치지 않고 이번 화면은 ZIP의 소수점 원문을 보존합니다. 차이 원인은 미확정입니다.

임장 활용: 이동 목적·연령·출발/도착 흐름은 주간 외래 유입을 검토할 후속 자료입니다. ‘병원 목적 이동’은 해당 내과의 환자 수·내시경 수요가 아니며, 철길 횡단이나 실제 건물 접근성도 별도 확인해야 합니다. 이번에는 이동 관측자료가 제공되지 않아 점수나 예상 환자수에 연결하지 않았습니다.

활용 매뉴얼은 분석 도구 사용 안내, 생활이동 상황판 매뉴얼은 지표·화면 정의입니다. 실제 이동 데이터와 구분합니다. 검토일2026-11-02.
